# Кто есть кто — лендинг

Одностраничный сайт личной CRM «Кто есть кто» — записной книжки для знакомых. Задача страницы одна: привести человека в приложение по кнопке «Открыть приложение».

Приложение живёт в отдельном репозитории, адрес — `https://app.whobook.ru`.

## Из чего сделано

- [Astro](https://astro.build) — статичная страница, без сервера и базы
- [Tailwind CSS 4](https://tailwindcss.com)
- pnpm

## Как запустить у себя

Нужны Node.js 22.12 или новее и pnpm.

```sh
pnpm install   # скачать библиотеки
pnpm dev       # открыть страницу на http://localhost:4321
pnpm build     # собрать готовый сайт в папку dist/
```

## Где что лежит

- `src/pages/index.astro` — сама страница, `src/components/` — её блоки
- `src/config.ts` — адрес приложения для кнопок
- `src/styles/tokens.css` — цвета, шрифты и отступы
- `design/` — макет: образец вида и тексты страницы

## Выкатка

Сайт — `https://whobook.ru`. Выкатка автоматическая, достаточно push в `main`:

1. GitHub Actions (`.github/workflows/deploy.yml`) собирает сайт в `dist/`. На сервере ничего не собирается.
2. Копирует `dist/` на сервер в `/var/www/whobook.ru` командой `rsync --delete`: лишние старые файлы удаляются.
3. nginx отдаёт эту папку. В конце Actions проверяет, что главная отвечает 200 и что на сайте именно новая версия: в `/version.txt` лежит номер коммита.

Ход и результат — во вкладке Actions на GitHub. Стенда и отката нет: сломалось — правим и пушим новую версию.

Доступ: GitHub заходит на сервер пользователем `landing` с ключом из секрета `LANDING_DEPLOY_KEY`. Этот ключ умеет только копировать файлы в папку сайта. Сервер подготовлен один раз скриптом `deploy/setup-server.sh`: он запускается от root, рядом с ним кладётся публичный ключ `landing-deploy.pub`. Чтобы сменить ключ: создать новую пару, приватную часть положить в секрет, публичную — рядом со скриптом и запустить скрипт ещё раз.
