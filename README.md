# Кто есть кто — лендинг

Одностраничный сайт личной CRM «Кто есть кто» — записной книжки для знакомых. Задача страницы одна: привести человека в приложение по кнопке «Открыть приложение».

Приложение живёт в отдельном репозитории, адрес — `https://app.whobook.ru`.

## Из чего сделано

- [Astro](https://astro.build) — статичная страница, без сервера и базы
- [Tailwind CSS 4](https://tailwindcss.com)
- pnpm

## Как запустить у себя

Нужны Node.js 22.12 или новее и pnpm.

```sh
pnpm install   # скачать библиотеки
pnpm dev       # открыть страницу на http://localhost:4321
pnpm build     # собрать готовый сайт в папку dist/
```

## Где что лежит

- `src/pages/index.astro` — сама страница, `src/components/` — её блоки
- `src/config.ts` — адрес приложения для кнопок
- `src/styles/tokens.css` — цвета, шрифты и отступы
- `design/` — макет: образец вида и тексты страницы

## Выкатка

Планируется так: push в `main` → GitHub Actions собирает сайт → копирует его на сервер. Пока не настроено.
