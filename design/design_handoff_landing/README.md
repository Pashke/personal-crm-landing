# Handoff: лендинг «Кто есть кто»

## Overview
Одностраничный статичный лендинг веб-приложения «Кто есть кто» (записная книжка для знакомых). Цель страницы одна: перейти в приложение по кнопке «Открыть приложение» (`https://app.<домен>`).

Стек: **Astro + Tailwind CSS 4**, статическая сборка, без клиентского фреймворка. Единственная интерактивность: аккордеон в блоке «Вопросы» (делать на нативных `<details>/<summary>` или крошечном inline-скрипте).

## About the Design Files
Файлы в этой папке — **дизайн-референсы в HTML**, а не продакшн-код. Их нужно воссоздать в Astro-компонентах с Tailwind-утилитами. Копировать разметку напрямую не нужно: в макетах всё на inline-стилях и на собственном рантайме (`support.js`).

Открыть макеты: положить папку целиком и открыть `.dc.html` в браузере (нужен `support.js` рядом).

- `Landing 3a.dc.html` — мобильная версия (макет 390px).
- `Landing 3a Desktop.dc.html` — десктопная версия (резиновая, контент до 1168px, рамки до 1280px).
- `landing-text.md` — исходные тексты. **Все тексты брать дословно из макетов.** Отличие от md: H1 — «Не забывай, о чём договорились» (без «вы»).

## Fidelity
**High-fidelity.** Цвета, шрифты, размеры и отступы финальные. Воспроизводить точно.

## Responsive
Одна страница, две раскладки:
- `< 768px` (`md` в Tailwind) — мобильная раскладка по `Landing 3a.dc.html`, контент на всю ширину экрана (макет 390px, тянется до 767px).
- `≥ 768px` — десктопная раскладка по `Landing 3a Desktop.dc.html`. Внутри десктопа многоколоночные сетки складываются в колонку на узкой ширине (`auto-fit / minmax` в макете).

Fluid-размеры в десктопе заданы через `clamp()` — переносить как есть (arbitrary values Tailwind, например `text-[clamp(40px,4.6vw,68px)]`).

## Секции (по порядку)

### 01 Первый экран
- **Mobile:** высота 844px (на проде — `min-h-svh`), padding 14px, внутри двойная рамка на всю площадь. Внутренний блок: padding 18/18/20, gap 18px.
  - Шапка: «Кто есть кто» слева, «Записная книжка» справа (лейбл gold).
  - Через 28px: пометка Caveat «запиши пару строк →», H1, абзац, кнопка на всю ширину, под ней «Бесплатно» (Caveat, по центру).
  - Через 24px: пример поиска — поле (cream фон, forest текст, иконка-кружок 12px с бордером 2px, введено «Ан» + мигающий/статичный курсор 1.5×18px) и список из 2 карточек в рамке `1px line-dark`, radius 4px: аватар-инициалы (первый — заливка gold, второй — контур gold), имя PT Serif 700 15px с подсветкой совпадения «Ан» цветом gold, под ним заметка 13px muted.
- **Desktop:** рамка max-w 1280px, padding внутреннего блока clamp(18px,3vw,36px) clamp(18px,4vw,56px) clamp(28px,5vw,64px), min-height min(760px, 100vh − 80px).
  - Шапка — grid `1fr auto 1fr`: «Кто есть кто» слева, «Записная книжка» по центру, справа кнопка-контур «Открыть приложение» (1.5px gold, radius 4px, padding 9×16).
  - Ниже две колонки (auto-fit, min 380px, gap clamp(40px,6vw,88px), по центру по вертикали): слева пометка + H1 + абзац (max-w 500px) + ряд [кнопка padding 0 36px | «Бесплатно»]; справа пример поиска (max-w 460px, прижат вправо).

### 02 Боль — фон cream, текст forest
- H2 «Память подводит в самый неудобный момент».
- Список из 4 пунктов: сверху линия `2px forest`, каждый пункт — ◆ (rust, 11–12px) + текст, разделители `1px line-light`, padding 16px (desktop 20px).
- Desktop: две колонки — H2 слева, список справа (auto-fit, min 360px).
- Отступы секции: mobile 56px 24px; desktop clamp(56px,8vw,112px) clamp(24px,5vw,64px). Контент max-w 1168px.

### 03 Как это работает — фон forest
- H2, затем 3 шага: круг с номером (gold) + заголовок шага (bold-часть из текста: «Запиши человека.» и т.д.) + описание muted.
- Mobile: шаги в столбик, номер слева от текста, gap 26px.
- Desktop: 3 колонки (auto-fit, min 280px), над ними линия `1px line-dark`, номер над заголовком.

### 04 Почему удобно — фон cream
- H2, затем 3 карточки в двойной рамке (forest): заголовок Oswald + описание.
- Mobile: столбик, gap 14px. Desktop: 3 колонки (auto-fit, min 300px), gap 20px, карточки одинаковой высоты.

### 05 Вопросы — фон forest
- H2, затем аккордеон из 5 вопросов: сверху линия `2px gold`, разделители `1px line-dark`. Строка вопроса: текст слева, «+» / «−» (Oswald 24–26px, gold) справа; высота строки ≥44px. Ответ под вопросом, muted, правый отступ 36px (desktop 48px).
- По умолчанию открыт первый вопрос; открыт максимум один (повторный клик закрывает).
- Desktop: flex-wrap — H2 `flex: 1 1 220px`, аккордеон `flex: 3 1 520px` (колонка вопросов примерно втрое шире заголовка).

### 06 Финальный призыв — фон forest
- Двойная рамка gold (mobile отступ 0 14px 14px; desktop max-w 1280px), всё по центру.
- H2 «Кого ты встретил на этой неделе?», абзац, кнопка «Открыть приложение» (mobile — на всю ширину; desktop — padding 0 40px), «Бесплатно», внизу лейбл «Кто есть кто» (Oswald 13–14px, gold).

## Interactions & Behavior
- Все CTA — обычные ссылки `<a href="https://app.<домен>">`. Hover: `opacity: .9`. Добавить видимый `focus-visible` outline (gold, 2px, offset 2px).
- Аккордеон FAQ — см. выше. Без анимации в макете; допустима короткая (150–200ms) раскрытия высоты.
- Пример поиска на первом экране статичный, декоративный (`aria-hidden="true"`), не реальный инпут.
- Анимаций и JS кроме FAQ нет.

## Открытые вопросы (из `landing-text.md`)
- **Подпись «Бесплатно» под кнопками — не решено.** Сделать флагом (prop компонента CTA / константа), по умолчанию — показывать.
- **Не выкатывать**, пока в приложении нет входа (обещание «Твои контакты никто, кроме тебя, не видит»).
- Отзывов нет и не добавлять.
- Имена и заметки в примере поиска («Анна Соколова», «Андрей Петров») — демонстрационные, согласовать с заказчиком.
- URL приложения в макетах — заглушка `https://app.example.com`; вынести в env/конфиг.
